# Quiz Builder Full Stack

An interactive web application for creating and taking quizzes for education, training, and entertainment.

## Project Overview

Quiz Builder Full Stack is designed to make quizzes easier to create, manage, and participate in. The project contains a frontend and a backend.

## Features

- Create and manage quizzes.
- Support different question types, such as multiple-choice and true/false.
- Allow users to participate in quizzes.
- Track quiz scores and results.
- Provide a simple, user-friendly interface.

## Technologies Used

- **Frontend:** React, HTML, CSS, JavaScript
- **Backend:** Node.js and Express.js
- **Version Control:** Git and GitHub

## How to Run the Project

### Frontend

1. Open a terminal in the frontend folder.
2. Install dependencies:

   ```cmd
   npm install
   ```

3. Start the development server:

   ```cmd
   npm run dev
   ```

4. Open the local URL displayed in the terminal.

### Backend

1. Open another terminal in the backend folder.
2. Install dependencies:

   ```cmd
   npm install
   ```

3. Start the backend using the start command configured in the backend's `package.json`.
